# README – Resume Builder Pro Custom GPT

# Project Overview

- Created a Custom GPT called “Resume Builder Pro” to help users create, improve, and tailor professional resumes. 
- Designed to optimise resumes for Applicant Tracking Systems (ATS) and job-specific applications. 
-	Built to support resume rewriting, keyword optimisation, and career-focused resume improvements. 

# Key Features

- Generates ATS-friendly resume content.
- Tailors resumes based on uploaded Job Descriptions.
- Rewrites work experience into professional achievement-focused bullet points. 
- Supports resume optimisation for different industries and experience levels. 
- Assists with cover letter generation and resume refinement. 
- Uses uploaded knowledge files for contextual resume tailoring. 
- Provides professional and concise resume formatting suggestions. 

# Technologies / Concepts Used

- OpenAI Custom GPT 
- Prompt Engineering 
- AI Resume Optimisation 
- ATS Keyword Matching 
- Knowledge File Integration 

# Deliverables

- Custom GPT configuration 
- Example prompts and outputs 
- Resume transformation examples 
- Screenshots of GPT interactions 

# Learning Outcomes

- Learned how to build task-focused Custom GPT solutions. 
- Improved understanding of ATS optimisation techniques. 
- Demonstrated how AI can automate resume customisation and career assistance workflows. 


# README – Google Apps Script Job Tracker Automation

# Project Overview

- Developed an intermediate-level Google Apps Script automation project to track job application emails automatically. 
- Integrated Gmail and Google Sheets to improve productivity and automate application tracking. 
- Designed to scan Gmail for job-related emails and record details into a Google Sheet. 

# Key Features

- Automatically scans Gmail for job application emails. 
- Detects possible rejection emails using keyword matching. 
- Records email details into Google Sheets automatically. 
- Uses time-driven triggers for scheduled automation. 
- Includes error handling using try-catch logic. 
- Prevents duplicate email entries in the tracking sheet. 

# Technologies / Concepts Used

- Google Apps Script 
- GmailApp 
- SpreadsheetApp 
- Google Sheets Automation 
- Trigger-based Automation 
- Error Handling 

# Deliverables

- Apps Script code
- Google Sheet integration
- Trigger configuration
- Automation workflow screenshots 

# Learning Outcomes

- Learned how to automate workflows using Google Apps Script.
- Improved understanding of Gmail and Google Sheets integration.
- Demonstrated how automation can improve productivity and job application tracking. 


# README – AI Interview Coach GPT Project

# Project Overview

- Created an AI-powered interview coaching workflow using structured prompt engineering techniques. 
- Designed to simulate a realistic interview preparation experience for users preparing for job interviews. 
- Built as a documentation and demo project with workflow examples and screenshots. 

# Key Features

- CV and Job Description intake process. 
- Automatically analyses candidate skills and role requirements. 
- Conducts a structured 20-question interview session. 
- Provides instant feedback after each answer. 
- Generates a final interview debrief report with strengths and improvement areas. 
- Uses STAR-based behavioural interview methodology. 

# Technologies / Concepts Used

- ChatGPT / Generative AI 
- Prompt Engineering 
- AI Workflow Design 
- Interview Coaching Logic 

# Deliverables

- Workflow documentation 
- Example prompts and responses 
- Screenshots demonstrating functionality 

# Learning Outcomes

- Learned how to structure AI conversations for guided workflows. 
- Improved understanding of prompt engineering and AI response control. 
- Demonstrated how AI can be used for interview preparation and coaching.
